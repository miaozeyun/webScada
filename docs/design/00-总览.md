# webScada 架构设计总览（P0 定稿 v1）

> Web 原生、轻量、低代码拖拽组态的实时监控大屏。只读监控，介于数据 BI 大屏与重型 SCADA 之间，面向中小工厂产线设备监控。开源核心免费 + 企业版收费。
>
> 本目录为第一阶段（纯设计，不含实现代码）交付物。五份专项文档口径已统一，冲突处以本总览的「统一口径速查」与《02-工程JSON数据结构》为契约中心。

## 硬性边界（第一版一律不做）

- ~~不做控制写入 / 闭环联锁，全链路只读~~ **M7（2026-10-20）已突破**：反控写通道上线（开关/多档/输入框指令/事件 writeVar），浏览器直连数据源（mqtt publish / rest POST / ws send / mock 回环）；**分享页恒只读**，仅编辑器预览可写，变量须显式 `writable=true`；闭环联锁仍不做。契约见《02-工程JSON数据结构》§7

- 数据载荷仅支持 UTF-8 JSON（点路径 + 数组下标提取），不支持 CSV/二进制

## 技术栈

前端 Vue3 + TypeScript + Vite + Pinia + Element Plus + ECharts，设备图元 SVG，原生 WebSocket；后端 FastAPI + PostgreSQL（异步 SQLAlchemy 2.0 + Pydantic v2 + Uvicorn + Loguru），MQTT 接入 EMQX；部署 docker-compose 四容器（nginx / server / postgres / emqx）。工程画面导出为 JSON。
注：本项目数据库用 PostgreSQL（按项目规格，覆盖全局默认的 MySQL）。

## 核心架构速览

```text
设备/网关 ──MQTT──▶ EMQX ──aiomqtt──▶ ┌─────────────────────────────┐
第三方 HTTP ──httpx 轮询──▶           │  FastAPI 单进程（全异步）      │
上游 WS ──websockets──▶               │  collector 四源归一            │
Mock 生成器 ────────────▶             │   → 变量级换算(工程值) → hub   │
                                      │   → rules_engine(阈值/回差)   │
                                      │   → ws_manager(100ms 合帧)    │
                                      └──────────┬──────────────────┘
                                                 │ WebSocket
浏览器(编辑器 JWT / 分享页 shareToken / iframe) ◀──┘
PostgreSQL: users / projects.doc(JSONB+revision) / share_links.doc_snapshot / alarm_records
```

要点：编辑态与运行态共用唯一组件渲染器（widgets/）；「发布」= 创建/刷新分享链接（冻结脱敏快照，编辑不污染线上）；报警优先级 静态 props < 绑定映射 < 报警态，唯一实现点 WidgetHost.vue。

## 统一口径速查（全文一致，改动须五文档同步）

- 接口前缀 `/api/v1`；WS 端点 `/api/v1/ws/runtime`
- 乐观锁 `revision INT` + `baseRevision`，冲突 409 `REVISION_CONFLICT`
- 变量换算（bitIndex 位提取 → scale/offset → precision）只在服务端入池前执行一次，全链路「工程值」单一口径；报警阈值按显示值配置
- 分享=快照（share_links.doc_snapshot），无 publish 状态机
- 凭证 Fernet 加密存库；所有出口脱敏；PUT 空串=保留、null=清除
- 校验失败统一 422 `{code, message, errors:[{path,message}]}`
- WS：P0 无订阅帧（连接即整工程订阅，subPages 为 P2 预留）；心跳服务端 20s ping×2 判死、客户端 30s 判线；error 帧 accept 后推送再 close 4000
- P0 多页面=手动页签切换（无自动轮播）；button 组件纯静态占位
- 浏览器基线 Chrome/Edge ≥ 90（es2020，不用 structuredClone）
- 规模基线：单机 2C4G 单 worker，≤50 连接、≤5000 变量、单页 ≤200 组件
