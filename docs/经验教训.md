## E2E / 测试

### [2026-10-22] 外发 webhook 类验收：先查渠道 URL 约束与节流语义
- **现象**：门禁要求报警 30s 内 POST 到本地 http 接收器，写入 `doc.settings.notify` 被 422 拒；监听脚本又因 notify 节流（缺省 300s/规则）误判链路失败。
- **根因**：渠道 URL 强制 `^https://`（防明文出口泄漏 secret 的刻意约束），与「本地明文接收」假定冲突；断言未考虑节流窗。
- **解决**：接收器侧 TLS（自签 CA 注入容器 certifi）；断言锚「渠道生效时刻之后触发的报警」。报警 status 枚举只有 `triggered/acked/cleared`。
- **预防**：外发验收先查 URL 方案约束，本地接收器默认按「TLS + 容器 CA 注入」准备；时序断言考虑节流窗。

### [2026-10-20] Playwright / 测试基建速查（四条）
- URL 断言一律精确前缀（`http://…/editor/`），`**` 通配不可靠。
- Element Plus 受控输入 `fill()` 无效，用 `pressSequentially`/`type` 键盘注入，写后 blur 触发校验。
- UI 登录受 IP 限流（默认 10 次/分），连续跑 E2E 会 429 且表现为「登录没反应」——复用 `storageState`，或测试环境 `RATE_LIMIT_ENABLED=false`。
- pytest-asyncio 每测试一个事件循环：引擎/全局连接必须每测试重建（conftest 已做）；env 必须在 import app 之前设置（settings 导入时读取）；`from tests.conftest import` 依赖 `pythonpath=["."]`（pyproject 已配），不要靠 pytest 隐式路径推导。

### [2026-10-27] 模块级单例状态跨用例残留（pytest 与 Pinia 双场景）
- **现象**：store 单测断言失败却逻辑正确——模块级 history 单例带着上一用例的条目；setActivePinia 只重置 store state，不重置模块级闭包。
- **解决**：单例显式导出，受影响 spec 的 beforeEach 里显式重置（history.clearAll）；业务代码仍只走 store action。
- **预防**：「状态在 Pinia 外」的单例（history/音频/WS 句柄）都要列入测试隔离清单。

## 前端

### [2026-10-21] 台账缩略图空白（html2canvas 现代颜色函数 + 保存竞态双因）
- **现象**：所有工程卡片永远「保存后自动生成」，doc 里根本没有 thumbnail，且无任何报错。
- **根因**：① TitleBar 用 `color-mix()`，html2canvas 不支持即整页截图抛错，catch 静默；② 手动保存「先截图后 PUT」期间 3s 防抖自动保存先把无缩略图 doc 落库并清 dirty，随后 save() 因 !dirty 直接返回。
- **解决**：渐变改固定 rgba；catch 留 console.warn；saveWithThumbnail 开头清掉待触发定时器；setThumbnail 标脏。
- **预防**：html2canvas 不支持 color-mix/color()/oklch，画布任何一处出现都全页失败；异步副作用必须与「标脏→保存」时序显式绑定；静默 catch 一律留日志。

### [2026-10-21] 常驻大屏的性能红线：只动 transform/opacity，缓冲必须封顶
- **现象**：分享页静置 2 分钟 Layout 60 次/秒（SMIL 液面动画）；JS 堆稳定但一体机发热卡顿。
- **解决/红线**：常驻页面禁用 SMIL、SVG 子元素动画、`background-position` 动画（都不走合成层）；管道流动用扩展伪元素 translateX + overflow 裁剪；AudioContext 卸载即 close（上限约 6）；ack id/历史缓冲封顶。验收用 CDP `Performance.getMetrics` 长跑看 layouts/nodes，别只看内存。

### [2026-10-21] 画布快捷键被吞：preventDefault 的焦点副作用
- **现象**：属性面板输入后画布 Delete 无反应；组内删除后 selection 残留幽灵 id。
- **解决**：画布各 pointerdown 先 `blurTypingTarget()`；deleteSelection 先收敛到当前上下文真实存在的 id；抽屉/预览打开时快捷键整体旁路（installKeyboard isBlocked）。
- **预防**：接管点击的画布/拖拽区必须显式处理焦点转移；快捷键「输入中」判定不能只看事件 target。

### [2026-10-21] 拖动/编辑卡顿四源（修复基线）
- 逐事件写 doc + 重算吸附 → rAF 合帧（抬起前 flush 末帧）；move 里 `getBoundingClientRect()` → 手势期缓存视口 rect；自动保存每次 html2canvas 整页截图 → 节流（60s，手动/导出/离开才 force）；`backdrop-filter` 每帧重算 → 去掉。
- **预防**：交互热路径禁止逐事件布局读取与全量序列化；「保存后副作用」一律节流或移出主线程。

### [2026-10-21] 模板/基线三坑
- 多行文本被压一行：`ellipsis` 默认 true（nowrap），`\n` 排版前显式 `ellipsis:false`。
- 深色画布文字消失：text/var-display 等默认色 `inherit` 落到黑字——深底模板所有文字组件显式给 color。
- `:has()`/容器查询超 Chrome 90 基线会**静默失效**：条件样式一律模板绑 class。

### [2026-10-20] 环境两条（已固化，防回退）
- vite 代理必须 `ws: true`，否则运行态 WS 永挂「连接中」（vite.config.ts）。
- dev 端口 5199 + `strictPort: true`：被占直接报错，防静默漂移打错 E2E 地址。

### [2026-10-20/26] 模块级会话缓存污染换账号会话（两处同根）
- **现象**：admin 退出换 viewer 仍能进 /admin、报警面板仍显示「确认」（点了才 403）；在途 `/auth/me` 迟到结果还会把旧角色写回。
- **解决**：缓存绑定当前 token、登出/进 login 即作废、作废用「请求身份比对」处理并发、同源请求单飞去重、失败不落缓存。
- **预防**：模块级「会话相关」缓存必须提供换账号失效入口并处理 in-flight 竞态。

### [2026-10-25] 表单「整对象替换」静默清空隐藏字段
- **现象**：改一次变量名称，Modbus 的 dataType/byteOrder/unitId 全丢、在产采集断连——表单没列的字段没有「保留」语义。
- **解决**：表单编辑一律合并写入（`{ ...existing, ...表单字段 }`）；换类型才整份替换 config。
- **预防**：新增字段先问「哪个编辑入口会把它弄丢」；用「导出→改一项→重导→再导出」往返用例钉死字段守恒。

### [2026-10-25] 批量导入默认按业务主键 upsert，不要「重复即跳过」
- **现象**：点表改地址重导全被跳过，只能删了重导、绑定跟着断。
- **解决**：CSV 按键 upsert（省略列保留旧值；已有变量保持原数据源，否则一次全表导入会把所有变量搬去同一源）；导入导出同格式可往返；删除前扫描引用并阻断。
- **预防**：跨对象批量更新必须区分「更新内容」与「不改身份字段」；破坏性操作前能回答「影响谁」。

### [2026-10-26] 运行态组件解析工程上下文：别依赖 editor store 残留
- **现象**：仿真台的历史图按「上一次编辑的工程」取数，无任何报错。
- **根因**：工程 id 解析链「组件配置 → editor store → 宿主注入」，路由切换不清理 projectId，非编辑器宿主被旧值压住。
- **预防**：任何非编辑器宿主必须显式声明工程上下文；新增宿主先检查历史组件解析链。

### [2026-10-26] 高频数据驱动图表：增量合并而非 notMerge
- **现象**：10Hz 值帧下 `setOption(o, true)` 每帧全量重建，仪表盘指针跳变、序列越长越卡。
- **解决**：按「结构签名」（series 数量/顶层键/轴型）判断——形状不变走合并（保留过渡动画），形状变化才重建；会增删的序列/组件必须进签名，否则合并残留旧配置。
- **关联**：[10-27] 渲染层再加 250ms 节流（leading 即时 + trailing 补帧，dispose 前 flush），10Hz 视觉无损。

### [2026-10-26] WS 事件驱动的 REST 刷新必须合帧 + 序号守卫
- **现象**：变量穿越阈值时报警面板并发发数十个 GET /alarms，旧响应覆盖新结果。
- **解决**：静默刷新 600ms 防抖；请求序号「最后一写胜出」；后台轮询失败只页内提示不弹 toast；页面隐藏暂停。
- **预防**：并发查询一律加序号；后台轮询失败与用户操作失败提示分开。

### [2026-10-26] 本地/服务端同构：业务事件字段必须一致
- **现象**：本地引擎报警事件缺 variableKey，仿真台组件报警色不渲染（服务端正常）。
- **预防**：同一事件在本地引擎与服务端 WS 两种模式下字段同构；新增宿主按「与服务端同构」清单核对。

### [2026-10-26] 页面框架层只允许一处实现 + 低频大依赖动态导入
- 五个视图各复制一份顶栏（高度/操作漂移）→ 抽 `AppBar.vue` 统一；复制布局前先找现有组件。
- html2canvas/mqtt 等只服务低频路径的依赖首屏动态 `import()`；同步工厂内懒加载必须覆盖「加载中 stop / 加载后 write」两个时序。
- 仿真台教训：定时器驱动的列表拆开「数据频率」与「展示频率」（sparkline 1Hz 预计算、趋势只记实际绘制的 ≤8 条、隐藏暂停）；渲染函数内不做数组复制/字符串拼接。

### [2026-10-27] 坐标系口径必须写进签名：组内粘贴偏移 + Ctrl+V 不跟鼠标
- **现象**：组内「粘贴到此处」偏移组原点（(200,100) 的组就偏 200×100）；Ctrl+V 永远 +10px 阶梯。
- **根因**：`pasteClipboard(at)` 的 `at` 口径含混——页面绝对坐标直接参与目标池相对坐标运算，组上下文少减一次组原点；键盘分支从不传 at。
- **解决**：at 统一页面绝对坐标，组上下文先 `at - eg.x/y`（pasteAnchor.spec 四用例锁语义）；CanvasStage 维护 lastPointerDesign 悬停轨迹（enter 重建 rect 缓存 / move 只换算 / 滚轮后刷新 / 离开清空回落阶梯）。
- **预防**：「指定坐标」API 注释必须写明坐标系；跨上下文坐标换算用同构单测兜底。

### [2026-10-27] 禁止 `var(--token, #字面量)`：陈旧 fallback 掩盖令牌漂移
- **现象**：11 处该写法中 2 个令牌根本不存在（fallback 即生效值）、其余 fallback 与真值不一致——五主题下错色；WidgetHost 报警兜底色非默认主题错色。
- **解决**：全部改裸令牌引用（不存在的换正确令牌）；CI 视觉令牌门禁（check_visual_tokens.cjs，基线外新增即红灯）。
- **预防**：令牌存在就裸引用；色值纪律靠门禁不靠约定。

### [2026-10-27] 嵌套容器上下文用路径栈建模，别用单 id 直查顶层
- **现象**：双击组内子组静默失败，深层组永远不可编辑；渲染侧祖先组不展开照样够不着。
- **解决**：`editingGroupPath` 路径栈（栈顶=editingGroupId 兼容）；enterGroup 在当前上下文直接子级逐层进入（防跨层跳入）；Esc/空白单击=退一级选回；面包屑跳层；「在路径上的组都展开子级」；锁定组双击 toast。
- **预防**：静默 return 的入口要么提示要么测试钉住；改上下文解析时 grep 全部直接赋值点（测试直改 state 会绕过 action 同步）。

### [2026-10-27] 选中框必须跟随节点自身旋转：「已知限制」= 用户眼里的重叠 bug
- **现象**：旋转过的组件一选中，斜置新内容 + 轴对齐旧框（带柄带 W×H 徽标）同屏叠加，被报「旋转重叠、未旋转的也显示」；doc 数据干净，纯渲染层假象。
- **解决**：sel-box 应用与节点相同 rotate——柄/徽标本就在组件自身坐标系（与 calcResize 对称点锚定数学一致），实测 footprint 逐像素重合。
- **预防**：注释里的「已知限制」要分级——影响感知且高频的必须排期补齐；渲染验证看「各视觉层 footprint 与语义一致」，不只看 DOM 存在。

## 后端

### [2026-10-28] 改初始密码 ≠ 改库内密码：create_admin 幂等不覆盖
- 把 `ADMIN_PASSWORD` 改成演示值后，已存在的 admin 仍是旧哈希（entrypoint 的 create_admin 仅在用户不存在时创建），登录依旧失败。**处置**：直接改库内哈希（`hash_password` + UPDATE，或走 `PUT /users/{id}/password` 通道），并同步 `.env`/`.env.example`/`config.py` 默认值/E2E 脚本，否则下次重建库又回到旧值。

### [2026-10-26] 一对多广播：序列化一次 + 并发发送
- 每 100ms 合帧对 N 连接各 dumps 一次、慢客户端按 per-conn 超时**串行**拖住同工程 → 广播前序列化一次，`asyncio.gather` 并发发送（连接级锁保帧序），失败逐个摘除。串行 fan-out 会把单点慢连接放大成全房间延迟。

### [2026-10-22] 测试基建两课
- 报警/规则测试随机挂 `InvalidRequestError`：notify 派生任务并发读库走模块级 SessionLocal 跨事件循环——不测外发链路的文件一律 autouse 打桩 `notify.send_alarm`；新服务提供 session_factory 测试缝。
- 测试直改 JSON 列后 `p.doc = dict(p.doc)` 不落库：flush 按值相等判净变更 → 用 `flag_modified` 显式标脏。

### [2026-10-22] 本地验证 alembic 迁移的 stamp 法
- SQLite 方言无 ALTER 约束能力（0002 即炸），迁移链只面向 PG（CI PG16 冒烟）。本地验单个迁移：空库 `alembic stamp <prev>` + `upgrade head` 只跑新段；SQLite URL 用 `sqlite+aiosqlite:///C:/绝对路径.db`。

### [2026-10-20] 查询串带敏感值：两层日志都要查
- WS token 走查询串进 uvicorn access log → `--no-access-log`，访问日志由 nginx 输出（token 掩码）。新增查询串敏感端点必查两层日志。

### [2026-10-25] 质量位传播两课（虚拟变量）
- 派生计算必须把「输入质量」当一等输入：scope 只收 good；求值失败把虚拟变量转 bad 写回并广播，不能静默保旧值——否则断线后虚拟变量继续输出「正常数」。
- stale 判定按变量类型分：hold 常量/计算点/订阅型稳态点「没新帧 ≠ 失效」（`_effective_stale_ms` 返回 0 或心跳 touch），否则正确传导规则会在另一类变量上制造大面积误报。

### [2026-10-25] 时序缓冲按事件时间取胜 + 外部时间戳不可信
- 同窗口乱序帧按到达顺序覆盖 → 入缓冲前比 ts，旧帧丢弃（默认按事件时间最大）。
- 上游时钟未对时/retained 旧消息污染历史与统计 → 偏差门限 `FRAME_TS_MAX_SKEW_MS`（缺省 300s）超限回落 now + 告警去重。外部时间戳一律先做偏差门限再入库。

### [2026-10-25] 链路健康由链路自己证明，不能由业务数据反推
- 订阅型稳态点永不推帧会被误判 stale；MQTT 死了值没变也可能迟报。采集源维护独立 `state/last_ok_ms`（连接/收发/心跳推进），comm_monitor 分型阈值扫描，「sys_comm:<dsId>」报警。
- 三个坑：内存断线集合必须在**写库成功后**更新（失败要重试）；源删空变量要走清除分支（否则报警永久悬挂）；快照短暂缺席连续 2 轮才判删除。

### [2026-10-25] 跨网络副作用先持久化再发送；触发/恢复成对设计
- 通知失败重试 3 次即丢、恢复不外发（值班员只知坏不知好）→ `notification_outbox` 落库补发（指数退避、死信、崩溃遗留回收），逐行处理自己兜异常；clear 路径同样外发（不受触发节流限制）。

### [2026-10-25] 克隆实体：身份字段与内容字段分开
- 深拷贝 doc 建新工程不重写 project.id → 保存 422 `project_id_mismatch`。复制操作先列「哪些是身份、哪些是内容」，身份重新生成并重跑不变量校验。

### [2026-10-27] 门禁命令的退出码 + JSONB 方言分派两课
- `pytest | tail` 管道吞退出码（exit 恒来自 tail）→ `PIPESTATUS[0]` 或 `set -o pipefail`；申报全绿前看统计行。
- 「接口不含 X」契约要落到 SQL 投影层验证（load_only 裁 doc 列；JSONB「只取一个标量」走路径投影）。
- variant 列（`JSON().with_variant(JSONB())`）在**表达式层不切方言**：`col['k'].astext` 炸 AttributeError → 显式 `cast(col, PG_JSONB)` 再取路径；SQLite 单测覆盖不了 PG 分支，必须在真 PG（compose/CI）过一遍。

## 部署 / 构建

### [2026-10-21] 非 root 容器落盘目录：镜像内预建 + chown
- 命名卷按镜像内目录属主初始化，镜像没预建就归 root → `mkdir -p /app/uploads && chown appuser` 再挂卷；运行时 mkdir 绕不过属主问题。

### [2026-10-20] 多阶段构建两条
- 依赖层禁止 `pip install .`（wheel 依赖源码，缺文件被旧缓存层掩盖）；构建异常先 `docker history` / `--no-cache` 排除缓存假象。
- 基础镜像走 `ARG REG_PREFIX` + 国内源（.env 可设镜像站前缀），不写死官方源。

### [2026-10-22] 面向实装版本写第三方代码（pymodbus 3.16 / asyncua 2.1 实录）
- 约束下界（>=3.9）解析到 3.16：legacy datastore 运行时写恒 DEVICE_BUSY；asyncua 2.x 五处 API 偏差（stop()/to_string()/显式 nodeId 两参/回调签名 DataChangeNotif/动态端口 bserver.port）。
- **预防**：面向 venv 实装版本写代码；新依赖先跑最小 spike（起停/订阅/browse/断线四象限）核对 API 形状。

### [2026-10-22] 复用应用镜像跑旁路容器 + 代码更新后的镜像分账
- ENTRYPOINT 写死启动序且不 `exec "$@"` → 旁路容器必须覆写 `entrypoint: []`。
- `compose up -d` 不重建已有 tag 镜像；共用 build context 的多服务镜像名各自分账——代码更新后先 grep 运行容器内新符号确认版本再验收。

### [2026-10-25] 备份/交付三课
- 备份清单按「数据存在哪」列全（uploads_data/emqx_data 不在库里）；脚本读配置以运行时实际值为准（`docker compose port`），不假设 shell 有 .env；长期容器显式日志轮转（x-logging 20m×5）。
- 离线交付包白名单收集（防带走 certs 私钥）；`docker compose config --no-interpolate` 保留占位；构建期变量（REG_PREFIX/密钥）随包落地，否则目标机 image not found。
- `set -u` 下禁止多变量 `local` 互相引用（参数统一先展开，`b=$((...a...))` 当场 unbound）；部署脚本先用 stub docker/curl 跑通「首装 + 健康失败回滚」两分支。

### [2026-10-26] 官网接入同容器 nginx 三坑
- envsubst 模板只在 `$1` 为 `nginx` 时执行（验证用 `docker run ... nginx -t`）；`gzip_types` 别显式写 text/html（与默认重复报错）；无哈希文件名的静态站不照搬 SPA immutable 长缓存（资源 1h、HTML no-cache）。

## 流程 / 文档

### [2026-10-21] 设计文档是规划稿：引用路径先核实
- docs/design 目录树与实际落位有漂移（CLAUDE.md 已声明以仓库为准）；写文档/引用路径前先全局搜索实际实现；大调整后回改 docs/design。

### [2026-10-22] 门禁结果只认「最后一次文件变更之后」的输出
- git stash/外部工具改盘后，编辑器里的旧认知 + 早期 vue-tsc 结果被沿用 → 提交态模板破损仍申报零错误。任何外部往返后：编辑前重读文件、提交前当前工作树重跑全部门禁。

### [2026-10-26] 能力已实现 ≠ 用户可用：组件必须有宿主
- AlarmBanner/AlarmPanel 功能完整却零引用，运行态报警零痕迹。验收要含「宿主编排后用户看得见」；交付前 grep 新组件/新配置项是否有引用与消费点。

### [2026-10-26] 匿名可达出口按「最小投影」而非「凭证脱敏」建模
- 分享页曾整份返回 doc：数据源 host/port、通知 URL 内嵌 token、寄存器地址全匿名可见。脱敏（sanitize_doc_for_output）与最小投影（sanitize_doc_for_share）分成两个函数；先按「攻击者拿到整份文档能反推什么」威胁建模。

### [2026-10-26] 服务端生成对外绝对 URL 三课
- nginx `Host $host` 丢端口 → `$http_host` + `PUBLIC_BASE_URL` 显式覆盖；前端复制用 location.origin 兜底；验收标准是「另一台机器能打开」。

### [2026-10-26] 敏感路径「移出仓库」≠「从历史消失」
- `git mv` 到 gitignore 目录会留「新增记录」；filter-repo 后 `refs/agents/*`/reflog 仍可达旧历史。处置验收 = 「对象级 + 所有 ref 可达范围」双重为零；先 bundle 备份，强推后协作者重新克隆。

### [2026-10-26] 资质声明绝不可预置占位假值
- 页脚预置假 ICP 备案号 + 个人备案站放企业销售页——备案号是资质声明不是可替换占位。可替换占位（域名/图片）可预置；资质/许可声明（ICP/公网安备/许可证号）没有就整行不写。个人主体备案不得出现企业表述与销售页。
