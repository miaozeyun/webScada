FAQ

您可能想了解

webScada 是什么？
webScada 是一款 Web 原生、轻量、低代码拖拽组态的工业实时监控大屏，面向中小工厂单机场景，介于数据 BI 大屏与重型 SCADA 之间，提供组态编辑、只读实时监控与报警展示。开源核心以 AGPL-3.0 授权，另提供企业版。
webScada 需要安装客户端或浏览器插件吗？
不需要。webScada 基于 HTML5，组态编辑与运行监控全部在浏览器中完成，客户端零安装、零插件，推荐 Chrome / Edge 90 及以上版本。
webScada 支持哪些数据源？
支持 MQTT、REST 轮询、WebSocket、Modbus TCP 与 Mock（演示）五类数据源，服务端常驻采集，数据源凭证 Fernet 加密存储。
webScada 的数据存储在哪里？
所有工程画面与实时、历史数据都保存在您自己服务器的 PostgreSQL 数据库中，源码与数据完全自持，不经任何第三方云；工程导出时凭证自动脱敏。
如何部署 webScada？
提供 Docker Compose 编排，一条命令拉起 nginx、FastAPI、PostgreSQL 与 EMQX 四个容器，内置 TLS 支持与备份恢复脚本。
开源核心可以用于商业项目吗？
开源核心以 AGPL-3.0 授权（网络服务须提供源码），遵守协议即可免费使用；闭源集成、白标 OEM 等商业授权属于企业版，欢迎商务洽谈。
webScada 支持什么规模？
规模基线为单机 2C4G 部署，可承载不超过 50 个连接、5000 个变量、单画面 200 个组件。
