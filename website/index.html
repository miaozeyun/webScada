FAQ

您可能想问

需要安装客户端或插件吗？
不需要。编辑画面和查看大屏都在浏览器里完成，推荐 Chrome / Edge 90 及以上版本；挂在车间的电视或一体机也不用装任何软件。
我厂里的设备能接进来吗？
支持 MQTT、Modbus TCP、OPC UA、REST 接口和 WebSocket 五类主流接入方式。PLC、仪表、传感器只要能提供其中任意一种，就可以把数据接进来；暂不支持的协议可联系我们评估。
数据存在哪里，会不会上传到第三方？
所有画面、实时数据和历史数据都保存在您自己服务器的数据库中，不经过任何第三方云；源码和数据都由您自己掌握。
晚上没人盯大屏，报警怎么办？
报警规则在服务器上 7×24 判断，不依赖浏览器是否打开。触发后可自动推送到钉钉、企业微信、邮箱或您自己的系统，发送失败会自动重试，成功与否都有记录可查。
设备断网或掉线，系统能发现吗？
能。设备通讯中断时系统会自动生成一条严重级别的「通讯中断」报警，恢复后自动解除，避免出现画面停住却没人发现的状况。
历史数据能存多久，能导出吗？
默认每 5 秒记录一次、保留 30 天，可按需调整；支持按时间段查询平均值、最大值、最小值，并一键导出 CSV（Excel 可直接打开）。
怎么收费？
核心功能以 AGPL-3.0 开源免费，不按点位或客户端数量收费。需要贴牌 OEM、闭源集成、主备冗余和 SLA 支持时，走商业授权，按项目报价。
部署复杂吗，需要什么样的服务器？
一条 Docker Compose 命令即可完成部署，一台 2 核 4G 的普通服务器就能跑起来，局域网内即可使用，不依赖公有云。
