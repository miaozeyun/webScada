能做什么

webScada 是一套装在您自己服务器上的工业监控大屏：拖拽搭画面、接入现场设备、异常自动报警、历史数据随时查。下面按日常使用的六件事来讲，每一件都已经是现在能用的功能，不是规划。

一、搭画面：像做 PPT 一样

不用写代码，拖进画布、摆好位置、连上数据就能用。

拖拽搭画面

数字、仪表、曲线、表格、开关、按钮……拖进来就能用，位置对齐自动吸附，摆得整整齐齐。

75 个现成行业图元

阀门、水泵、罐体、暖通、管件、水处理、电力、仪表等 9 大类，全是自绘图形，拖进来就能用。

模板和「我的图元」

光伏、换热、空压、污水等示例画面照着改；常用的设备组合存成自己的图元，下个项目直接复用。

改错了也不怕

50 步撤销重做，组件可跨画面复制粘贴，旋转、缩放、多选批量调整，自动保存防丢失。

画面会「动」

数值变化、颜色切换、显示隐藏、闪烁、管道流动、风机旋转、小车沿路线走，都能跟真实数据联动。

点一下就有反应

点击、双击、右键都能设置动作：切换画面、弹出明细、打开网页、下发开关或设定值。

二、接设备：新老设备都能接

现场常见协议都支持，采集在服务器上跑，不占操作电脑。

六类数据来源

MQTT、Modbus TCP、OPC UA、REST 接口、WebSocket 五类现场协议，外加模拟数据用于演示和联调。

点位多也不怕

几百个变量用 CSV 表格一次性导入，自动识别重复项；32 位寄存器、字节序、从站号这些细节都照顾到了。

数据自动换算

倍率、偏移、小数位、取某一位，按变量单独设置；原始值进来就变成您要看的工程值。

断了会重连，掉线会报警

网络抖动自动重连；真的断了，系统会生成一条严重报警，恢复后自动解除，不用人盯着猜。

设备账号加密保存

数据源的账号密码加密存在数据库里，查看详情、导出工程、分享画面时自动隐藏，不会跟着文件外泄。

采集不占电脑

数据由服务器常驻采集，关掉浏览器、关掉大屏，采集和报警照常运行。

三、盯报警：异常第一时间找到人

报警不只是一块红条，而是一条完整的「发现 → 通知 → 处理 → 恢复」链路。

规则您来定

高于、低于、超过多久才算，一条规则可以组合设置；分提示、警告、严重三个级别。

四路通知渠道

报警一触发，自动发到钉钉群、企业微信群、邮箱，或者您自己的系统接口。每个渠道可单独设级别门槛。

发不出去会重试

网络抖动导致的发送失败自动重试三次；每条通知发没发出去、试了几次、卡在哪，都有记录可查。

报警中心，交接有据

独立页面查看所有报警：什么时候触发、谁确认的、何时恢复。交接班不用再翻聊天记录。

设备失联算报警

不只是数值超限。设备、网关、网络断了，同样按严重报警处理，恢复后自动记录解除时间。

大屏上也看得见

运行画面顶部有报警横幅、列表和提示音，现场抬头就能看到，和手机通知是同一套数据。

四、查数据：昨天的数据今天还能查

数据自动存，不用额外装数据库或做报表工具。

自动记录 30 天

默认每 5 秒记一次，保留 30 天，可按您的需要调整，不用自己写采集脚本。

曲线对比

多条曲线同屏看，时间段随意缩放；平均值、最大值、最小值、最新值随时切换。

实时表和历史表

除了曲线，还能用表格展示：当前所有点位一览，或按小时汇总的历史数据，汇报时更直观。

一键导出表格

选好点位和时间段，直接导出 CSV，Excel 打开就能用；30 天数据也能一次导完。

数据不丢

工程、报警、历史值都存在数据库里，附带的备份脚本可按天自动备份，误删也有恢复路径。

随时回看报警记录

每个报警的触发值、恢复值、确认人、时间都留着，出问题复盘时按时间一筛就清楚。

五、给人看：一条链接就够

不用给别人开账号，也不用远程帮人装软件。

发链接就能看

生成一条只读链接，客户、领导、外场同事打开浏览器就能看实时大屏，不用登录、不用装东西。

只读，改不了

分享出去的画面只能看，改不了工程、也控制不了设备，发得放心。

能定时失效、随时撤销

默认 30 天有效期，可选 7 天、90 天或永久；项目结束后点一下撤销，链接立即失效。

改完一键更新

画面调整后点「刷新」，已发出去的链接会自动看到新版，不用重新发一遍。

大屏、手机都适配

自动等比例适配常见的 16:9 大屏、拼接屏和笔记本；竖屏安装的现场也能强制旋转显示。

必要时能下发指令

开关、档位、数值设定都能从画面下发。只有明确标记为「可写」的点位才允许操作，分享页保持只读。

六、管起来：账号、权限、备份有着落

给车间用，光好看不够，还得管得住。

三种角色

管理员管全部，操作员能改画面和确认报警，访客只能看。谁该能做什么，分得清清楚楚。

关键操作留痕

登录、改工程、确认报警、导出数据等操作都有审计记录，出了问题能追溯到人。

一条命令部署

Docker 一键装好，普通服务器就能跑；支持内网离线环境，不用连公有云。

备份和恢复

数据库、工程文件、上传的图片都能一起备份，默认保留 14 天，恢复脚本带检查。

全站可加密

支持 HTTPS 访问，账号密码加密保存，改密码后其他设备上记住的登录会自动失效。

规模说清楚

单台 2 核 4G 服务器可带 5000 个变量、单画面 200 个组件、50 个同时在线大屏，够中小厂区用。

技术细节（给工程师看）

上面讲人话，这里给需要评估的人看具体口径。

数据接入与换算
  • 数据源：MQTT（支持 + / # 通配与写回）、Modbus TCP（线圈/离散输入/输入寄存器/保持寄存器，批量读、32 位读写、四种字节序、变量级从站号）、OPC UA（订阅推送、节点浏览）、REST 轮询、WebSocket、模拟源。
  • 变量换算：服务端入池前统一执行 bitIndex → scale/offset → precision，界面与报警阈值统一按工程值口径。
  • 虚拟变量：表达式引用其它变量的 key，支持 sin/cos/atan2/exp/log/clamp 等函数与 _tick 秒节拍。
  • 凭证：数据源密码库内加密存储（Fernet），详情、导出、分享快照一律脱敏；Webhook 类渠道强制 HTTPS。
报警与通知
  • 规则：阈值（> ≥ < ≤ == !=）、回差、持续判定；报警状态机 triggered → acked → cleared。
  • 通知渠道：工程内配置优先，未配置回落服务端环境变量；渠道级 minLevel 过滤，同一规则 300 秒节流。
  • 投递：网络类失败重试 3 次（1s/2s/4s 指数退避），落 outbox 记录（sent / 待补发 / 死信），可查询。
  • 通讯中断：轮询源 3×采集周期、OPC UA 30 秒、长连接 90 秒静默判定，恢复自动解除。
历史数据与分享
  • historian：默认 5 秒采样、30 天保留；查询支持 avg/min/max/last/sum 聚合，单次跨度 ≤30 天、≤20 个 key。
  • CSV 导出：keyset 分页流式输出，30 天 5 秒采样约 51.8 万行不整载内存；JWT 与分享 token 双通道鉴权。
  • 分享：签发时冻结脱敏快照，默认 30 天有效期，可撤销、可刷新；撤销/过期即时断开在线连接。
部署、权限与规模
  • 部署：Docker Compose 四容器（nginx / FastAPI / PostgreSQL / EMQX），支持国内镜像加速与非 root 运行。
  • 权限：admin / operator / viewer 三角色，八类操作审计；访问令牌 2 小时，可选「记住此终端」刷新令牌轮换。
  • 规模基线：单机 2C4G，≤50 个 WebSocket 连接、5000 变量、单页 200 组件，doc > 2MB 拒绝保存。
  • 浏览器：Chrome / Edge 90+，构建目标 ES2020；不用 structuredClone 等新 API。
  • 技术栈：Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts；FastAPI + SQLAlchemy 2.0 + Alembic + Pydantic v2；PostgreSQL；EMQX。
