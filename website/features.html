功能特性

webScada 的功能覆盖组态编辑、数据接入与运行、报警与历史、安全部署四个环节：41 种组件与 75 个行业图元拖拽搭画面，MQTT / REST / WebSocket / Modbus TCP 五类数据源接入，服务端 7×24 报警与历史趋势，Docker Compose 一键部署。以下能力均已在当前版本实现。

组态编辑器

低代码拖拽搭建工业画面，像画图一样简单。

对齐吸附与旋转缩放

图元对齐吸附、自由旋转与缩放，多选批量操作，画面摆放整齐利落。

50 步撤销与跨页粘贴

完整撤销重做历史，图元可跨画面复制粘贴，误操作随时回退。

我的图元资产库

自绘符号一键入库，跨工程复用，沉淀企业专属图元资产。

75 行业图元与画面模板

9 大类自绘图元 + 7 件画面装饰，配合画面模板与标题栏，风格统一开箱即改。

数据绑定与状态动画

数值、颜色、显隐多维度绑定，状态动画让画面随实时数据「活」起来。

工程管理与导入导出

工程 CRUD 带乐观锁（409 冲突检测），导入导出自动脱敏凭证，多画面统一管理。

数据接入与运行

服务端常驻采集，浏览器只负责展示与交互。

五类数据源

MQTT / REST 轮询 / WebSocket / Modbus TCP / Mock，服务端常驻采集，断线不丢规则。

凭证加密存储

数据源凭证 Fernet 加密落库，运行态带鉴权连接，测试结果自动注回。

编辑 / 运行分离

编辑态与运行态彻底解耦，运行引擎轻量加载，大屏 7×24 挂机稳定。

分享快照发布

运行画面一键生成分享链接（token 访问），分享页恒只读，可挂无人值守大屏。

反控写指令

开关、多档、输入框三类写控，仅限显式 writable 变量，分享页恒只读。

WS 合帧推送

WebSocket 实时推送自动合帧，亚秒级刷新，多连接并发受控。

报警与历史

监控不因页面关闭而中断，数据闭环留痕可查。

服务端 7×24 报警判定

阈值 / 回差 / 持续时间规则组合，报警在服务端持续判定，与浏览器无关。

报警 ack 状态机

单行状态机流转（触发→确认→恢复），站内横幅 + 列表双呈现，处置全程留痕。

Webhook 与邮件外发

报警触发即推送 Webhook 回调或邮件，无缝接入企业微信、钉钉等值班体系。

历史趋势 historian

服务端 5s 采样、30 天保留、区间聚合查询，浏览器本地存储仅作离线兜底。

多曲线趋势对比

基于 ECharts 的历史曲线组件，多变量同屏对比、区间缩放随取随查。

数据落库可回溯

工程、报警、历史值统一存 PostgreSQL（JSONB + revision 乐观锁），审计有据可查。

安全、部署与运维

从开发环境到生产现场，交付路径短且可控。

RBAC 与操作审计

admin / operator / viewer 三级角色，八类关键操作全程审计留痕。

全站 TLS 与 EMQX 收口

TLS 1.2/1.3 全站加密，EMQX 禁用匿名连接、强制内置库鉴权，安全基线开箱达标。

Docker Compose 一键部署

nginx / FastAPI / PostgreSQL / EMQX 四容器编排，一条命令拉起，镜像加速构建。

备份与恢复

整库 dump + 工程 JSON 导出双备份，14 天滚动保留，恢复脚本带健康校验。

明确的规模基线

单机 2C4G 可承载 ≤50 连接 / 5000 变量 / 单页 200 组件，边界清晰不打太极。

CI 质量门禁

每个 PR 自动跑后端（PostgreSQL 迁移冒烟 + pytest）与前端（vue-tsc + build）双流水线。
